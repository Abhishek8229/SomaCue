# Phase 2A notes: historical baseline artifacts

The committed files `docs/3d-lab/results.json`, `docs/3d-lab/browser-checks.json`, and the screenshots in `docs/3d-lab/screenshots/` were generated by the original experiment, before the Phase 2A repairs. They are retained as a historical baseline, not as current evidence of the lab's behavior.

Phase 2A changed some displayed measurements and browser checks:

- The height-matched sensitivity row now reports its missing soft-tissue metrics as **Not measured** instead of the fabricated `100%` inside and `0%` edges-over-25% values.
- The soft-tissue deformation criterion now reports **Not measured** and cannot pass when no clip sample contains an edge measurement.
- The animation clock holds at the clip duration when scrubbed to the end instead of wrapping to zero.
- Switching poses now stops runtime playback as well as updating the controls.
- The pause check reads the actual animation clock, and the browser verification now includes an endpoint-clock regression check plus aggregation and unmeasured-criterion checks.

The historical files were deliberately not overwritten or regenerated. Do not treat them as the result of the current code, and do not edit them in place to represent the fixed runtime. A future verification run must produce fresh artifacts in a separate location, or in a new baseline that is reviewed explicitly. `pnpm verify:3d-lab` currently writes to the historical paths, so it must not be run as a non-destructive check without first arranging a separate output location.
